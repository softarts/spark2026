JupyterHub / Notebook

登录后进入 JupyterLab。示例位于 work/examples/（每次启动 Notebook Server 时从镜像刷新）。

新用户在 /hub/signup 注册，管理员 spark 在 /hub/authorize 批准后才能登录。每个用户的 Notebook 运行在自己的命名空间 user-<用户名>。

管理员密码由 startcluster.sh 打印，保存在 Mac 上的 .lab/credentials.env。

Spark UI — Notebook Driver

Local Mode 与 Kubernetes Client Mode：Driver 就在 Notebook Pod 的 Jupyter kernel 进程里。

地址 /spark-ui/<用户名>/。只有 SparkSession 存活时才有内容；仅转发该用户 Notebook Pod 的 4040 端口（第一个 Session）。

…

Spark UI — Cluster Mode Driver Pod

Kubernetes Cluster Mode：spark-submit 在用户命名空间中创建的独立 Driver Pod。地址 /spark-driver/<用户名>/。

只在 Driver Pod 运行期间可用；作业结束后 Driver Pod 变为 Completed，UI 随之消失。

Silo Object Storage Console

S3-compatible 对象存储（PGSTY 维护的 MinIO 社区分支）的 Web 控制台：浏览 Bucket、预览和下载对象。

Console 登录使用 Silo 管理员密钥（只有平台管理员持有，.lab/credentials.env）。Notebook 中使用的是所有用户共享的非 root 用户 lab-user。集群内 S3 Endpoint：http://silo.spark-lab.svc:9000。
